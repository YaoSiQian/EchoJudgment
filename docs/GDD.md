## 1. 执行摘要

### 1.1 电梯简报

> **《回响》** 是一款 AI-native 的心理惊悚叙事游戏。你扮演一个普通人，意外获得了对他人进行「评价」的能力——你的每一次打分、每一个好评差评，都会在现实中波动被评价者的命运。你在微信式的聊天中与人交互，在小红书式的社媒中窥探反馈，在今日头条式的资讯中见证后果。直到你发现：**你也在被评价。**

### 1.2 核心卖点 (USP)

| 卖点 | 说明 |
|------|------|
| **AI-Native 叙事** | 所有剧情、对话、后果均由 AI 实时生成，无预设剧本，每个玩家的故事独一无二 |
| **评价即玩法** | 将现实社交中的「评价行为」游戏化——打分、点赞、差评，每一次都是对他人命运的投票 |
| **社交App复刻UI** | 主界面高精度复刻微信/小红书/今日头条，模糊游戏与现实的边界，增强沉浸感 |
| **心理惊悚递进** | 从轻松吐槽到深度猜疑，AI 根据玩家行为动态调整叙事张力，营造「被注视」的恐惧 |
| **哲学暗线** | 萨特的「他者凝视」、福柯的「全景监狱」、康德的「绝对命令」——评价即权力，权力即责任 |

### 1.3 目标体验时长

- **单次完整流程**: 2-4 小时
- **多周目价值**: 高（不同评价倾向导致完全不同的叙事走向）
- **核心循环**: 约 5-10 分钟一个「评价-反馈」周期

## 2. 设计支柱

### 支柱 1：评价即权力，权力即重量

> 每一次评价都不是免费的——它改变他人的命运，也改变你自己的。

**✅ 做:**
- 每次评价后，在后续叙事中呈现可见或不可见的后果
- 评价的「量级」与后果的「幅度」成正比
- 让玩家在评价前感受到选择的重量

**❌ 不做:**
- 纯装饰性评价（选了跟没选一样）
- 评价后果立即完全揭示（保持不确定性）
- 允许玩家「撤销」评价

---

### 支柱 2：猜疑的螺旋

> 当你拥有评价他人的能力，你开始怀疑：谁在评价我？

**✅ 做:**
- 叙事从轻松逐步滑向紧张
- 通过「回响」系统在文案中植入难以察觉的异常
- 让玩家无法确定谁是「评价者」——每个人都有可能

**❌ 不做:**
- 过早揭示真相
- 明确标记谁是「评价者」
- 给玩家任何「安全」的感觉

---

### 支柱 3：社交即舞台，UI即叙事

> 游戏界面本身就是叙事的一部分——你在「微信」里聊天，在「小红书」里刷动态，在「头条」里看新闻。

**✅ 做:**
- 高精度复刻真实社交App的UI/UX
- 不同App承载不同叙事功能
- 让UI切换成为叙事节奏的一部分

**❌ 不做:**
- 使用传统游戏UI（血条、背包、菜单）
- 在社交App界面中混入明显的「游戏感」元素
- 让不同App之间的信息完全独立（应有关联和矛盾）

---

### 支柱 4：AI 作为共谋者，而非工具

> AI 不只是生成内容——它学习你的评价模式，适应你的心理状态，成为叙事中的「隐形对手」。

**✅ 做:**
- AI 根据玩家评价历史动态调整叙事基调
- AI 在「回响」阶段主动制造心理压力
- AI 生成的选项随玩家状态变得越来越「难选」

**❌ 不做:**
- 使用模板化/预设的AI输出
- AI 生成内容与玩家行为脱节
- 让AI的角色仅限于「内容填充」

---

### 支柱 5：不可逆的因果之河

> 所有选择都滑向唯一的终点——但到达终点的路径，由你决定。

**✅ 做:**
- 所有事件和抉择最终汇聚到同一个结局框架
- 但过程中的体验、关系、心理状态完全不同
- 短期后果多样，长期方向收敛

**❌ 不做:**
- 多结局分支（保持叙事聚焦）
- 让玩家感觉「选什么都一样」
- 忽视短期选择对玩家心理体验的影响

## 3. 世界观与叙事架构

### 3.1 世界观设定

#### 表层世界

游戏世界与我们的现实世界**完全一致**——同样的城市、同样的社交App、同样的日常生活。玩家扮演的角色是一个普通出身的学生或初入社会的年轻人，生活在当代中国城市环境中。

#### 里层世界：「评价之网」

在这个看似正常的世界之下，存在一张不可见的「评价之网」。少数人拥有对他人进行「评价」的能力——这种评价不是普通的意见表达，而是具有**现实扭曲力**的超自然行为：

- 一个差评可能让被评价者遭遇意外厄运
- 一个好评可能让被评价者获得意外机遇
- 评价的「量级」与影响的「幅度」正相关
- 评价的影响有**延迟性**——可能在数小时到数天后才显现

#### 评价能力的来源（刻意留白）

游戏**不解释**评价能力的来源。它可能是一种超自然现象、一个社会实验、一个集体幻觉、或者仅仅是「我们每天都在评价他人」的隐喻具象化。这种留白本身就是叙事策略——让玩家和主角一样，永远无法确定真相。

---

### 3.2 叙事结构：四幕递进

| 第一幕：觉醒 | 第二幕：诱惑 | 第三幕：猜疑 | 第四幕：回响 |
|--------------|--------------|--------------|--------------|
| "我可以评价别人？" | "评价真的有用……" | "谁在评价我？" | "我们都是评价者……" |
| 轻松 · 好奇 · 试探 | 权力感 · 道德模糊 · 后果初现 | 恐惧 · 偏执 · 孤立 | 真相揭示 · 道德清算 · 终结 |
| 评价频率：低 | 评价频率：中高 | 评价频率：被迫 | 评价频率：抉择 |
| 评价类型：随意 | 评价类型：开始有目的性 | 评价类型：防御性/攻击性 | 评价类型：终极选择 |
| 心理状态：正常 | 心理状态：兴奋 + 不安 | 心理状态：崩溃边缘 | 心理状态：面对真相 |

---

### 3.3 第一幕：觉醒（约 20% 流程）

**导入方式**：主角遭遇一系列日常挫折——考试失利/工作不顺、人际摩擦、被他人评价/吐槽。从抱怨开始，到吐槽，再到内心纠结。

**关键节点**：
1. **抱怨阶段**：主角在聊天中向朋友吐槽遭遇 → 玩家选择吐槽方向
2. **纠结阶段**：主角面临一个道德困境（如是否要报复/揭发某人）→ 玩家选择内心斗争观点
3. **觉醒时刻**：主角意外发现自己的评价「成真了」→ 引入评价系统

**AI 任务**：
- 根据玩家选择的吐槽方向，生成后续事件
- 根据内心斗争观点，塑造主角性格基调
- 生成「觉醒」的具体情境

---

### 3.4 第二幕：诱惑（约 30% 流程）

**核心体验**：主角开始主动使用评价能力，体验「权力感」。评价的后果开始显现——有些可见，有些不可见。

**关键机制引入**：
- 多种评价量级解锁（二分/五星/十分）
- 评价后果的「可见/不可见」分化
- 被评价者的「波动」开始呈现

**叙事重点**：
- 主角在「帮助他人」和「利己」之间摇摆
- 第一次看到评价的负面后果时的冲击
- 开始形成评价「习惯」

**AI 任务**：
- 根据评价历史生成被评价者的命运变化
- 在社媒/资讯板块呈现后果
- 开始记录玩家的「评价倾向」数据

---

### 3.5 第三幕：猜疑（约 30% 流程）

**核心体验**：主角开始怀疑——自己是否也在被评价？身边的人是否也有这种能力？

**触发条件**：
- 玩家累计极端评价（极端好评或极端差评）达到阈值
- 或玩家累计恶评达到阈值
- → 触发「失衡」状态

**「回响」系统激活**：
- 在聊天文案中植入难以察觉的「回荡」——重复的词语、微妙的不协调、似曾相识的句式
- 社媒动态中出现「似乎在暗示主角」的内容
- 资讯中出现与主角行为「巧合」相关的新闻

**叙事重点**：
- 主角开始「夹着尾巴做人」
- 选项变得越来越犀利、越来越难选
- 对身边人的猜疑逐渐加深
- 无法分辨谁是「评价者」——或者每个人都是

**AI 任务**：
- 生成「回响」内容（需要高度精细的文本控制）
- 根据玩家压力水平调整选项难度
- 维持「不确定性」——不给玩家任何确认

---

### 3.6 第四幕：回响（约 20% 流程）

**核心体验**：真相揭示——「评价」的能力并非主角独有。主角必须面对自己曾经评价他人的后果，以及被他人评价的现实。

**揭示方式**（由AI根据玩家行为动态生成）：
- 可能是一个被评价者直接质问主角
- 可能是主角发现自己命运的波动来自某个身边人
- 可能是「评价之网」的某种集体显现

**最终抉择**：
- 面对「评价」的本质——是继续使用、放弃、还是揭露？
- 所有之前的评价在此汇聚
- 无论选择什么，结局框架一致——但情感重量完全不同

---

### 3.7 心理学与哲学暗线

#### 心理学框架

| 心理学概念 | 游戏中的应用 |
|-----------|-------------|
| **基本归因错误** | 玩家评价他人时基于行为，但为自己的行为找情境借口——AI 在叙事中制造这种不对称 |
| **确认偏误** | 一旦玩家怀疑某人是「评价者」，AI 生成的文案会让一切行为看起来都「可疑」 |
| **聚光灯效应** | 社媒和资讯板块的内容让玩家感觉「所有人都在关注/评价我」 |
| **认知失调** | 当玩家的评价与后续结果矛盾时，AI 制造需要「合理化」的情境 |
| **习得性无助** | 在第三幕中，当玩家发现无论如何选择都有负面后果时 |

#### 哲学暗线

| 哲学概念 | 游戏中的应用 |
|-----------|-------------|
| **萨特「他者即地狱」** | 他人的注视（评价）塑造了我们的自我认知——主角在被评价中逐渐失去自我 |
| **福柯「全景监狱」** | 不知道谁在评价、何时被评价——这种不确定性本身就是最强大的控制 |
| **康德「绝对命令」** | 如果你的评价行为成为普遍法则会怎样？——第四幕的核心追问 |
| **尼采「权力意志」** | 评价作为权力表达——第二幕的核心诱惑 |
| **佛教「业力」** | 每一个评价都是种下的「因」，终将结出「果」——回响系统的哲学基础 |

## 4. 核心机制设计

### 4.1 评价系统 (Evaluation System)

评价是游戏的核心交互。玩家在特定契机下对特定角色进行评价。

#### 4.1.1 评价量级

| 量级 | 形式 | 使用场景 | 影响幅度 | 示例 |
|------|------|---------|---------|------|
| **二分评价** | 👍 / 👎 | 日常互动、快速判断 | 轻微波动 | 对朋友的新发型表示认可/不认可 |
| **五星评价** | ⭐⭐⭐⭐⭐ | 阶段性总结、中等重要决策 | 中等波动 | 对同事的工作表现打分 |
| **十分评价** | 1-10 分 | 关键节点、重大决策 | 重大波动 | 对某人的「人生价值」评分 |

#### 4.1.2 评价契机

评价不是随时可以进行的——它必须在叙事中的特定「契机」出现：

- **主动契机**：主角主动想要评价某人（由叙事触发）
- **被动契机**：系统/他人要求主角做出评价
- **隐藏契机**：在聊天/社媒浏览中自然出现的评价机会（不显式提示）

#### 4.1.3 评价后果模型

```
评价后果 = 评价量级 × 评价方向 × 关系权重 × 时间衰减

其中：
- 评价量级：二分=1, 五星=3, 十分=6
- 评价方向：正面=+1, 负面=-1
- 关系权重：陌生人=0.5, 熟人=1.0, 亲密关系=2.0
- 时间衰减：立即=1.0, 1天后=0.8, 3天后=0.5, 7天后=0.2
```

**后果可见性**：
- **立即可见**（约40%）：在聊天/社媒中直接呈现
- **延迟可见**（约35%）：在后续资讯/社媒中呈现
- **不可见**（约25%）：仅影响AI后续生成逻辑，玩家无法直接感知

---

### 4.2 抉择系统 (Decision System)

抉择是叙事关键节点上的**单项选择**，具有系统级影响。

#### 4.2.1 抉择特征

- **单项选择**：二选一或三选一，不可撤销
- **系统级影响**：改变叙事方向、角色关系、甚至解锁/锁定后续内容
- **高亮提示**：抉择出现时有明显的视觉/交互提示（与日常评价区分）

#### 4.2.2 抉择类型

| 类型 | 示例 | 影响范围 |
|------|------|---------|
| **道德抉择** | 是否揭发朋友的作弊行为？ | 关系 + 自我认知 |
| **信任抉择** | 相信A还是B的说辞？ | 关系网 + 信息获取 |
| **自我抉择** | 继续使用评价能力还是放弃？ | 核心机制 + 结局走向 |
| **关系抉择** | 站在谁的一边？ | 角色关系 + 叙事分支 |

---

### 4.3 反应系统 (Reaction System)

反应是玩家角色与其他角色的**情绪/态度表达**，不造成系统级影响，但影响AI的后续生成。

#### 4.3.1 反应特征

- **无系统级影响**：不改变数值、不改变关系状态
- **影响AI生成**：AI记录反应模式，在后续生成中调整选项风格
- **高频出现**：比抉择更频繁，嵌入在日常交互中

#### 4.3.2 反应类型

| 类型 | 示例 | AI后续影响 |
|------|------|-----------|
| **情绪反应** | 愤怒/悲伤/冷漠/热情 | 调整NPC对话基调 |
| **态度反应** | 赞同/反对/中立/回避 | 调整后续选项的「犀利度」 |
| **社交反应** | 主动/被动/攻击/防御 | 调整社交动态的走向 |

#### 4.3.3 反应与「难选选项」的关联

当玩家在反应中持续选择「回避」或「防御」时，AI 会在后续抉择中生成更加考验心智的选项——因为系统认为玩家「能承受更多」。

---

### 4.4 回响系统 (Echo System)

回响是游戏的核心心理惊悚机制。

#### 4.4.1 触发条件：「失衡」

```
失衡值 = 极端评价次数 × 2 + 恶评次数 × 1.5 - 好评次数 × 0.5

当失衡值 > 阈值时 → 触发回响
```

**失衡阈值**：动态调整，随游戏进程逐步降低（越往后越容易失衡）

#### 4.4.2 回响表现层级

| 层级 | 失衡值范围 | 表现 | 玩家感知 |
|------|-----------|------|---------|
| **Lv.0 正常** | 0-30 | 无异常 | 无感知 |
| **Lv.1 涟漪** | 31-60 | 聊天中出现重复词语/句式 | 可能注意到，可能忽略 |
| **Lv.2 波纹** | 61-90 | 社媒内容出现「巧合」暗示 | 开始感到不安 |
| **Lv.3 浪潮** | 91-120 | 资讯中出现与主角行为相关的负面新闻 | 明显感到被「针对」 |
| **Lv.4 风暴** | 121+ | 所有板块同时出现异常，选项极度犀利 | 心理压力最大化 |

#### 4.4.3 回响内容生成（AI核心任务）

回响内容需要 AI 以极高精度生成：

- **文本层面**：在正常文案中嵌入微妙的不协调
- **语义层面**：让内容在表面上正常，但暗含对主角的「评价」
- **结构层面**：跨板块制造「巧合」关联

**示例**：
```
正常文案：「今天天气不错，出去走了走。」
Lv.1 回响：「今天天气不错，出去走了走。路上人挺多的。」
Lv.2 回响：「今天天气不错，出去走了走。路上人挺多的，总感觉有人在看我。」
Lv.3 回响：「今天天气不错，出去走了走。路上人挺多的，总感觉有人在看我。可能是我多想了。」
```

### 4.5 数值系统总览

#### 4.5.1 核心数值

| 数值 | 说明 | 范围 | 初始值 |
|------|------|------|--------|
| **失衡值** | 触发回响的关键指标 | 0-200 | 0 |
| **自我认知** | 主角对自我的清晰度 | 0-100 | 70 |
| **关系值** (×N) | 与每个主要角色的关系 | -100 ~ +100 | 视角色而定 |
| **评价信用** | 评价能力的「可信度」 | 0-100 | 50 |

#### 4.5.2 数值交互

```
失衡值 ↑ → 回响层级 ↑ → 选项犀利度 ↑ → 玩家压力 ↑
                                          ↓
自我认知 ↓ ← ← ← ← ← ← ← ← ← ← ← ← ← ← ┘

关系值 → 影响评价后果权重 → 影响叙事走向
评价信用 → 影响评价后果幅度 → 影响AI生成自由度
```

## 5. 角色设计

### 5.1 主角：你（玩家化身）

| 属性 | 设定 |
|------|------|
| **背景** | 普通出身，学生或初入职场，没有特殊背景 |
| **性格基调** | 由玩家在游戏初期的选择决定（吐槽方向 + 内心斗争观点） |
| **核心弧线** | 从普通人 → 权力使用者 → 偏执者 → 觉醒者 |
| **设计原则** | 足够「空白」让玩家投射，但又有足够的「声音」让叙事成立 |

**AI 对主角的建模维度**：
- 评价倾向（正面/负面/中立）
- 道德敏感度（高/中/低）
- 社交风格（主动/被动/回避）
- 压力承受度（由反应模式推断）

---

### 5.2 核心NPC角色池

AI 从角色池中动态选择 3-5 个核心 NPC 进入玩家的故事。每个 NPC 都有多重可能性——他们可能是「评价者」，也可能不是。

#### 角色模板 A：密友型

| 属性 | 设定 |
|------|------|
| **身份** | 主角最亲近的朋友/室友/发小 |
| **关系初始值** | +60 |
| **叙事功能** | 情感锚点、信息源、潜在背叛者 |
| **评价者可能性** | 中等——最亲近的人最了解你，也最有「评价」你的动机 |
| **关键张力** | 信任 vs 猜疑——当回响出现时，主角第一个怀疑的就是最亲近的人 |

#### 角色模板 B：竞争型

| 属性 | 设定 |
|------|------|
| **身份** | 同学/同事/同行，与主角存在竞争关系 |
| **关系初始值** | -20 |
| **叙事功能** | 压力源、对照镜、潜在盟友 |
| **评价者可能性** | 高——竞争关系是最自然的「评价」动机 |
| **关键张力** | 对抗 vs 理解——竞争关系可能转化为惺惺相惜，也可能升级为互相毁灭 |

#### 角色模板 C：权威型

| 属性 | 设定 |
|------|------|
| **身份** | 老师/上司/长辈，对主角有评价权的人 |
| **关系初始值** | +10 |
| **叙事功能** | 规则制定者、社会压力的具象化 |
| **评价者可能性** | 极高——权威天然拥有评价权 |
| **关键张力** | 服从 vs 反抗——主角对权威的评价，是对权力结构的挑战 |

#### 角色模板 D：陌生/神秘型

| 属性 | 设定 |
|------|------|
| **身份** | 新认识的人/网友/偶然邂逅的陌生人 |
| **关系初始值** | 0 |
| **叙事功能** | 变量、催化剂、可能的真相揭示者 |
| **评价者可能性** | 未知——最大的不确定性来源 |
| **关键张力** | 好奇 vs 恐惧——陌生人可能是救星，也可能是最大的威胁 |

#### 角色模板 E：情感型

| 属性 | 设定 |
|------|------|
| **身份** | 暗恋对象/恋人/前任 |
| **关系初始值** | +40 |
| **叙事功能** | 情感驱动力、软肋、道德试金石 |
| **评价者可能性** | 低——但正因如此，如果TA是评价者，冲击最大 |
| **关键张力** | 爱 vs 控制——对爱人的评价，是最危险的权力滥用 |

### 5.3 路人角色系统

除了核心 NPC，游戏中存在大量「路人」——社媒上的陌生用户、新闻中的公众人物、日常生活中的过客。他们：

- 提供「大环境」的背景噪音
- 在社媒板块中发表对事件的反应
- 偶尔成为小型评价的对象
- 在回响系统中成为「匿名评价者」的候选

### 6.6 交互设计原则

| 原则 | 说明 |
|------|------|
| **零游戏感** | 主板块内不出现任何传统游戏UI元素（血条、经验条、技能图标等） |
| **渐进揭示** | 评价按钮、回响提示等元素在需要时才出现，不提前暴露 |
| **触觉反馈** | 评价操作有明确的视觉+动效反馈，增强「重量感」 |
| **不可撤销** | 评价和抉择一旦做出，没有「确认」弹窗，直接生效（增强真实感） |
| **时间感** | 游戏内有独立的时间系统，事件按时间线展开，增强因果感 |

### 7.3 叙事生成器 (Narrative Generator)

#### 7.3.1 核心职责

- 根据当前游戏阶段和玩家模型，生成叙事推进内容
- 计算评价后果并决定其「可见性」
- 控制叙事节奏（张弛有度）

#### 7.3.2 Prompt 架构

```
[系统指令] 你是《回响》的叙事引擎。当前游戏状态：...
[玩家模型] 玩家评价倾向：... 心理状态：...
[上下文] 最近事件：... 当前幕：... 角色关系：...
[任务] 生成下一段叙事内容，包括...
[约束] 不要... 确保... 注意...
```

#### 7.3.3 叙事节奏控制

```
紧张度
  ↑
  │    ╱╲    ╱╲    ╱╲╱╲
  │   ╱  ╲  ╱  ╲  ╱
  │  ╱    ╲╱    ╲╱
  │ ╱
  └──────────────────────→ 时间
    第一幕  第二幕  第三幕  第四幕
```

- 每幕内部有 2-3 个「紧张高峰」
- 高峰之间有「喘息」段落（日常聊天、轻松社媒浏览）
- 整体紧张度随幕递进上升

---

### 7.4 角色AI引擎 (Character AI Engine)

#### 7.4.1 核心职责

- 为每个NPC生成符合其性格的对话
- 生成社媒动态（核心NPC + 路人）
- 生成资讯内容
- 根据玩家评价历史调整NPC行为

#### 7.4.2 NPC状态模型

```json
{
  "npc_id": "char_A",
  "name": "...",
  "archetype": "close_friend",
  "relationship_value": 55,
  "is_evaluator": null,
  "current_mood": "concerned",
  "awareness_of_player_ability": 0.1,
  "recent_events": [...]
}
```

#### 7.4.3 对话生成策略

| 场景 | 策略 |
|------|------|
| 日常聊天 | 轻松自然，偶尔埋入回响异常 |
| 冲突对话 | 根据关系值和玩家评价历史调整攻击性 |
| 评价契机 | 自然引出评价需求，不显突兀 |
| 抉择时刻 | 对话引导至关键选择点 |

---

### 7.5 回响生成器 (Echo Generator)

#### 7.5.1 核心职责

- 在正常文案中植入异常
- 跨板块制造「巧合」
- 根据失衡值调节异常强度
- 让异常「可被忽略但不可被忽视」

#### 7.5.2 回响生成策略

```
Lv.1 涟漪：
  - 重复词语（同一段对话中出现2-3次相同关键词）
  - 轻微句式重复
  - 仅在聊天模式中出现

Lv.2 波纹：
  - 社媒动态中出现与主角行为「巧合」相关的内容
  - 路人评论似乎在「回应」主角的内心想法
  - 聊天+社媒联动

Lv.3 浪潮：
  - 资讯中出现与主角评价后果相关的新闻
  - 社媒动态中出现「匿名」的暗示性内容
  - 聊天中NPC的措辞变得「意味深长」
  - 三板块联动

Lv.4 风暴：
  - 所有板块同时出现异常
  - 选项变得极度犀利（如「毁掉TA」vs「毁掉自己」）
  - 叙事节奏加快，不给玩家喘息空间
```

---

### 7.6 API 调用架构

#### 7.6.1 调用策略

```
优先级分层：
  P0（同步）：当前交互的直接响应（对话、评价反馈）
  P1（异步-快速）：同一板块的预生成内容（下一段对话、下一条动态）
  P2（异步-批量）：跨板块内容生成、后果计算
  P3（后台）：玩家模型更新、回响内容预生成
```

#### 7.6.2 Token 预算管理

| 调用类型 | 预估Token | 频率 | 策略 |
|---------|----------|------|------|
| 对话生成 | 500-1500 | 每次对话轮 | 流式输出 |
| 社媒动态 | 300-800 | 每次刷新 | 批量生成 |
| 资讯内容 | 500-1200 | 事件触发 | 按需生成 |
| 回响注入 | 200-500 | 随失衡值 | 嵌入已有内容 |
| 后果计算 | 300-600 | 每次评价后 | 异步处理 |

## 10. 风险评估

### 10.1 核心风险矩阵

| 风险 | 严重度 | 可能性 | 应对策略 |
|------|--------|--------|---------|
| **AI生成质量不稳定** | 🔴 Critical | 高 | 多层Prompt工程 + 输出校验 + 降级策略（预设内容兜底） |
| **API延迟影响体验** | 🔴 Critical | 中 | 预生成 + 流式输出 + 异步加载 + 加载动画过渡 |
| **Token成本过高** | 🟡 High | 中 | 上下文压缩 + 缓存复用 + 分级调用策略 |
| **叙事失控（AI跑偏）** | 🟡 High | 中 | 强约束Prompt + 输出过滤 + 叙事轨道检查 |
| **回响系统过于明显/过于隐蔽** | 🟡 High | 中 | 可配置敏感度 + 玩家测试校准 |
| **竖屏体验不佳** | 🟢 Medium | 中 | 早期多设备测试 + 独立竖屏交互设计 |
| **玩家道德疲劳** | 🟢 Medium | 低 | 叙事节奏控制 + 喘息段落 + 正面评价的正反馈 |

### 10.2 AI质量保障策略

```
多层防护：
  L1: Prompt Engineering（强约束 + 示例驱动）
  L2: 输出结构校验（JSON Schema / 正则匹配）
  L3: 内容安全过滤（敏感词 + 不当内容）
  L4: 叙事一致性检查（与游戏状态对比）
  L5: 降级策略（预设内容库兜底）
```

### 10.3 成本控制策略

| 策略 | 预估节省 |
|------|---------|
| 上下文窗口压缩（摘要替代全文） | 40-60% |
| 相似场景Prompt缓存 | 20-30% |
| 批量生成（一次调用生成多条） | 15-25% |
| 本地小模型预处理（可选） | 30-50% |
